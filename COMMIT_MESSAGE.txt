## Verification Steps

```bash
# 1. Build the project
./gradlew clean build --no-daemon

# 2. Start the Docker stack
docker-compose up -d

# 3. Wait for services to boot (check Eureka)
curl http://localhost:8761

# 4. Verify Vault secrets are loaded
docker exec -it vault sh -c "vault kv get secret/auth-service"

# 5. Verify Config Server loads secrets
curl http://localhost:8888/actuator/health

# 6. Test the order flow
curl -X POST http://localhost:8080/orders \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "user-123",
    "items": [{"productId": "PROD-001", "quantity": 2, "price": 29.99}]
  }'

# 7. Monitor Kafka topics (if needed)
docker exec -it kafka kafka-console-consumer.sh \
  --bootstrap-server localhost:9092 \
  --topic order-events \
  --from-beginning
```
